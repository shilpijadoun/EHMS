# Hotel Palace

Hotel Palace is a React and Vite frontend for hotel guests, administrators, and staff.

## Run locally

```sh
npm install
npm run dev
```

## Available commands

- `npm run dev` starts the local development server.
- `npm run build` creates a production build in `dist/`.
- `npm run lint` checks the JavaScript and JSX source.
- `npm run preview` serves the production build locally.

The current room, booking, and staff records are sample data stored in the page components.
